Kindle Wireless Sync

Receive books from Calibre's wireless device connection straight into a jailbroken Kindle's built-in library. Latest release: @VERSION@.

Install with KPM

You need a jailbroken Kindle with KPM installed. With Wi-Fi on, in kterm or over SSH on the Kindle, add this repository once and install:

kpm add-repo @INDEX_URL@
kpm update
kpm install kindle-wireless-sync

Run kpm update and kpm install kindle-wireless-sync again to upgrade. Your settings are kept. Install from this repository rather than from a downloaded .kpkg file: KPM can't upgrade a package installed from a file.

Use

  1. In Calibre, choose Connect/share → Start wireless device connection.
  2. On the Kindle, open Wireless Sync from the Library, tap Find libraries, then Allow your library.
  3. Send books from Calibre as usual. They appear in the Kindle library as soon as each transfer finishes.
